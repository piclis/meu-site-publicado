Sobre Mim

Desenvolvedor Web & Estudante de Tecnologia

Olá! Sou Arthur Wiggers, um desenvolvedor web apaixonado por criar soluções digitais funcionais e visualmente atraentes. Atualmente, estou cursando Publicação de Aplicações Web e aprimorando minhas habilidades em desenvolvimento front-end.

Meu objetivo é criar experiências de usuário excepcionais, combinando design criativo com código limpo e eficiente. Acredito que a tecnologia deve ser acessível e intuitiva para todos.

Quando não estou codando, gosto de explorar novas tecnologias, participar de comunidades de desenvolvimento e contribuir para projetos open source.
