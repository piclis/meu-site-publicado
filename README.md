## 📋 Descrição do Projeto

Este projeto consiste em um site pessoal/portfólio desenvolvido como parte da unidade curricular **Publicar Aplicações Web**. O site apresenta uma landing page responsiva e moderna que demonstra minhas habilidades em desenvolvimento front-end, seguindo as melhores práticas de HTML5, CSS3 e JavaScript.

O site inclui seções para apresentação pessoal, habilidades técnicas, projetos desenvolvidos e um formulário de contato funcional, implementando todos os conceitos revisados durante a unidade curricular.
